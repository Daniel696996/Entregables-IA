MEDNEXUS OS - GUIA RAPIDA
=========================

QUE ES
------
Demo bilingue de operaciones hospitalarias con panel de seguridad, red de
hospitales, asistente de voz, equipo medico, inventario, agenda, consulta
asistida y expedientes con estudios sinteticos.

INICIAR
-------
Necesitas Node.js 20.9 o posterior y npm.

1. Abre una terminal en la carpeta MedNexus-OS.
2. Ejecuta:

   npm install
   npm run dev

3. Abre http://localhost:3000 en el navegador.

Para compilar y servir:

   npm run build
   npm start

CAMBIAR IDIOMA, ROL Y TEMA
--------------------------
Usa ES / EN para cambiar idioma y Clinico / Paciente para cambiar de espacio.
El selector de rol es una vista de demostracion, no autenticacion.
Usa Claro / Oscuro en la barra superior. La preferencia queda guardada en el
navegador.

FUNCIONES
---------
Clinico:
- Seguridad clinica y topologia 3D con diez nodos y metricas ficticias.
- Asistente de voz/texto con comandos locales para navegar, consultar equipo
  disponible e inventario. Web Speech API muestra transcripcion cuando el
  navegador la admite y concede permiso de microfono.
- Accesos de ejemplo: pregunta que medicos estan disponibles, que referencias
  estan bajo minimo o solicita abrir la agenda.
- El asistente responde con reglas y fixtures locales; no es IA generativa.
- El enlace a AztecLab abre su pagina informativa; no hay API de voz de AztecLab
  conectada en esta demostracion.
- Consulta asistida por pasos: sintomas, zona, intensidad, antecedentes y
  señales autodeclaradas. No diagnostica ni calcula urgencia clinica.
- Hospitales de Medellin con buscador, selector, contactos y enlaces a Maps.
  Con clave de Google se consultan lugares y tiempos de ruta; sin clave se ve
  un directorio local y distancia aproximada en linea recta.
- Agenda con citas ficticias pasadas/futuras. Crea, edita y elimina citas,
  guardias, cirugias o reuniones; los eventos se guardan en localStorage.
- Equipo con perfiles ilustrativos, incluyendo Jose Daniel Pabon Villanueva y
  Valentina Rios. Camilo Jaramillo y Yuliana Perez tienen fichas con permisos
  y actividad simulados.
- Inventario con filtros y modelos 3D educativos.

Paciente:
- Consulta resumen, reserva ficticia y directorio hospitalario.
- Abre consulta asistida desde la navegacion.
- Las fichas incluyen notas, signos vitales, alergias, tratamientos ficticios,
  auditoria y tres estudios de imagen sinteticos por paciente.
- Ayuda segura muestra orientacion general y simulacion visual de llamada.

GOOGLE MAPS
-----------
Copia .env.example a .env.local y define NEXT_PUBLIC_GOOGLE_MAPS_API_KEY.
Habilita Maps JavaScript API, Places API (New) y Routes API, y restringe la
clave al origen web. Reinicia Next.js despues del cambio. Google puede cobrar
las solicitudes de Places y Routes.

El mapa pide ubicacion solo si el usuario lo permite. Sin clave se mantienen
la busqueda local, los telefonos publicados y enlaces a rutas externas.

DATOS Y SEGURIDAD
-----------------
Los pacientes, antecedentes, signos vitales, profesionales, certificaciones,
contadores, existencias, turnos y citas son ficticios o ilustrativos. Las
credenciales de los perfiles no estan verificadas. Los telefonos y direcciones
del directorio tienen enlaces a las paginas oficiales para su confirmacion.

Los modelos y estudios son sintéticos y no diagnostican. La aplicacion no
prescribe, no genera citas reales, no llama a emergencias, no almacena audio ni
se conecta a hospitales. El numero +57 000 000 0000 es invalido y solo aparece
en la simulacion. En Medellin se muestra 123 como linea de emergencia.
